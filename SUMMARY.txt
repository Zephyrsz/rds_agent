💡 核心洞察
====================================================================

1. Metadata 是 RDS Agent 的核心
   → 指标定义被访问 5+ 次（最高频）
   → 表结构被访问 6+ 次
   → 几乎每个节点都依赖 metadata

2. YAML 方案适合中小规模
   → 简单、直观、版本控制友好
   → 适合 < 50 表的场景
   → 启动快，内存占用小

3. SQLite 适合大规模和高级功能
   → 支持 100+ 表的场景
   → 支持动态更新、版本管理
   → 支持复杂查询和全文搜索
   → 启动时间提升 5-10x

4. API 兼容层是平滑迁移的关键
   → 保持 100% API 兼容
   → 用户无感知迁移
   → 支持渐进式切换
   → 降低迁移风险
