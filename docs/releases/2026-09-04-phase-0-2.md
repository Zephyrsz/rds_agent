# Phase 0-2 文档快照

## 快照说明

这是 `meta-in-sqlite` 分支在 `2026-09-04` 的工作树快照，不是带 Git tag 的正式产品发布。正式发布前必须把 `code_revision` 和 `documentation_revision` 替换为不可变 commit/tag，并补充发布审批信息。

## 交付范围

- Phase 0：SQLite schema、兼容模型、YAML 迁移、SDK 默认 SQLite 和端到端基线。
- Phase 1：Domain、Entity、Measure、Metric、Dimension、Term、Filter 等语义契约。
- Phase 2：`SemanticQuery`、确定性 Compiler、Join 安全、SQLGuard 和 Workflow 接入。

## 运行时边界

SDK/MCP 使用 SQLite metadata 和 Compiler；REST、Function Calling、LangChain 仍保留 YAML + LLM 兼容路径。业务查询继续使用 DuckDB。
