### 2. 关键差距（阻塞性问题）

| 差距 | 影响 | 严重程度 |
|------|------|---------|
| **无 Entity 和语义图** | 无法防止数据膨胀，聚合结果可能错误 | 🔴 极高 |
| **Measure/Metric 混淆** | 指标口径不统一，每次查询可能不一致 | 🔴 极高 |
| **无 Domain** | 无法支持多业务场景，限制产品适用范围 | 🔴 极高 |
| **权限治理不足** | 仅表白名单，无法企业级部署 | 🔴 极高 |
| **缺少 Trusted Assets** | 关键财务/董事会指标无法锁定口径 | 🔴 极高 |
